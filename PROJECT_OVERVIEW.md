# 📋 Полный обзор проекта Zaman AI Assistant

## 🎯 Общее описание

**Zaman AI Assistant** — это инновационный AI-ассистент для Zaman Bank, разработанный для HackNU/25. Проект представляет собой полнофункциональный прототип банковского AI с эмоциональным интеллектом, геймификацией и проактивными советами по исламским финансам.

### Ключевые особенности
- **Эмоциональный интеллект**: Real-time анализ эмоций клиентов
- **RAG-система**: Семантический поиск по базе знаний исламских финансов
- **Исламская геймификация**: Челленджи без азарта с духовными наградами
- **Проактивность**: AI сам инициирует диалог при триггерах
- **Мультимодальность**: Текстовый и голосовой режимы

## 🏗️ Архитектура системы

### Backend (FastAPI + Python)

#### 1. **main.py** - Главное приложение
- **Назначение**: Точка входа FastAPI приложения
- **Функции**: 
  - Инициализация CORS middleware
  - Подключение всех роутеров
  - Запуск базы данных при старте
  - Health check endpoint

#### 2. **config.py** - Конфигурация
- **Назначение**: Централизованное хранение настроек
- **Содержит**:
  - API ключи OpenAI
  - Параметры базы данных
  - Настройки RAG (ChromaDB)
  - Лимиты токенов для LLM
  - Триггеры проактивных уведомлений

#### 3. **prompts.py** - Промпты для LLM
- **Назначение**: Централизованное хранение всех промптов
- **Содержит**:
  - Системный промпт
  - Промпт для анализа эмоций
  - Промпты для определения намерений
  - Специализированные промпты для целей

### Модели данных (SQLAlchemy)

#### 1. **user.py** - Модель пользователя
- **Поля**: id, name, phone, created_at
- **Relationships**: Связи с conversations, goals, emotion_logs, challenges, transactions
- **Функции**: Автоматическое создание пользователей

#### 2. **goal.py** - Финансовые цели
- **Поля**: title, target_amount, current_amount, deadline_months, status
- **Функции**: 
  - Автоматический расчет прогресса в процентах
  - Поддержка статусов (active, completed, cancelled)
- **Бизнес-логика**: Отслеживание прогресса достижения целей

#### 3. **emotion_log.py** - Логи эмоций (Emotional DNA)
- **Поля**: emotion_type, stress_score, financial_vulnerability, notes
- **Назначение**: Построение эмоционального профиля клиента
- **Анализ**: 10-балльная шкала стресса, определение уязвимости

#### 4. **conversation.py** - История диалогов
- **Поля**: message, role, emotion_score, emotion_type
- **Назначение**: Сохранение контекста диалога
- **Использование**: Для построения промптов с историей

#### 5. **challenge.py** - Челленджи
- **Поля**: title, description, challenge_type, target_value, current_value
- **Функции**: Отслеживание прогресса выполнения челленджей
- **Типы**: no_impulse, savings, deposit, reduce_spending, stress_management

### Сервисы (Бизнес-логика)

#### 1. **rag_engine.py** - RAG система
- **Назначение**: Семантический поиск по базе знаний
- **Технологии**: ChromaDB + OpenAI embeddings
- **Функции**:
  - Векторизация текстовых файлов
  - Семантический поиск (top-3)
  - Проверка релевантности запросов
  - Форматирование контекста для LLM
- **База знаний**: 31 чанк из FAQ, продуктов и глоссария

#### 2. **llm_service.py** - LLM сервис
- **Назначение**: Работа с OpenAI API
- **Модели**: gpt-5-mini, text-embedding-3-small
- **Функции**:
  - Chat completion с настройками
  - Генерация embeddings
  - Извлечение JSON из ответов
  - Определение намерений пользователя
- **Особенности**: Обработка ошибок и fallback

#### 3. **emotion_analyzer.py** - Анализ эмоций
- **Назначение**: Real-time анализ эмоционального состояния
- **Функции**:
  - Анализ сообщений через LLM
  - Определение типа эмоции
  - Расчет стресса (1-10)
  - Оценка финансовой уязвимости
- **Контекст**: Генерация текстового описания для промптов

#### 4. **prompt_builder.py** - Построение промптов
- **Назначение**: Динамическое создание промптов для LLM
- **Функции**:
  - Построение чат-промптов с контекстом
  - Создание промптов для определения намерений
  - Форматирование эмоционального контекста
  - Интеграция истории диалогов

#### 5. **gamification.py** - Геймификация
- **Назначение**: Исламская геймификация без азарта
- **Шаблоны челленджей**:
  - "30 дней без импульсивных трат"
  - "Накопить 100,000₸ за 3 месяца"
  - "Открыть первый депозит Вакала"
  - "Сократить траты на 20%"
  - "Неделя без стресс-покупок"
- **Награды**: Духовные (Сабр, Баракат) вместо материальных

#### 6. **proactive_agent.py** - Проактивные уведомления
- **Назначение**: Автоматические уведомления клиентам
- **Триггеры**:
  - Высокий стресс 2+ дня подряд
  - Цель близка к дедлайну (60 дней)
  - Неактивность 5+ дней
  - Челлендж близок к завершению (80%+)
- **Функции**: Генерация персонализированных сообщений через LLM

#### 7. **voice_service.py** - Голосовой сервис
- **Назначение**: Обработка голосовых сообщений
- **Технологии**: Whisper-1 для распознавания, TTS для ответов
- **Функции**:
  - Speech-to-text
  - Text-to-speech
  - Кодирование/декодирование аудио

#### 8. **ai_analytics.py** - Аналитика
- **Назначение**: Анализ финансовых данных клиентов
- **Функции**:
  - Анализ банковских выписок
  - Категоризация транзакций
  - Генерация финансового контекста для чата
  - Сравнительная аналитика

### Роутеры (API Endpoints)

#### 1. **chat.py** - Главный чат
- **Endpoints**:
  - `POST /api/chat` - Основной чат
  - `GET /api/conversation/{user_id}` - История диалогов
  - `POST /api/goal/create` - Создание цели
  - `DELETE /api/goal/delete/{user_id}/{goal_id}` - Удаление цели
- **Функции**:
  - Обработка текстовых и голосовых сообщений
  - Анализ эмоций
  - Определение намерений
  - Генерация ответов через LLM
  - Рекомендация продуктов

#### 2. **goals.py** - Управление целями
- **Endpoints**:
  - `GET /api/goals/{user_id}` - Получение целей
  - `POST /api/goals` - Создание цели
  - `PATCH /api/goals/{goal_id}` - Обновление цели
  - `DELETE /api/goals/{goal_id}` - Удаление цели
- **Функции**: CRUD операции с финансовыми целями

#### 3. **challenges.py** - Челленджи
- **Endpoints**:
  - `GET /api/challenges/{user_id}` - Получение челленджей
  - `POST /api/challenges` - Создание челленджа
  - `PATCH /api/challenges/{challenge_id}` - Обновление прогресса
  - `GET /api/challenges/templates/list` - Список шаблонов
- **Функции**: Управление исламскими челленджами

#### 4. **profile.py** - Профиль пользователя
- **Endpoints**:
  - `GET /api/profile/{user_id}` - Получение профиля
  - `POST /api/proactive/check/{user_id}` - Проверка триггеров
- **Функции**: Профиль и проактивные уведомления

#### 5. **analytics.py** - Аналитика
- **Endpoints**:
  - `POST /api/analytics/upload` - Загрузка выписки
  - `GET /api/analytics/{user_id}` - Получение аналитики
  - `POST /api/analytics/analyze` - Анализ транзакций
- **Функции**: Анализ финансовых данных

## 🔄 Потоки данных

### 1. **Основной поток чата**
1. Пользователь отправляет сообщение (текст/голос)
2. Обработка голосового ввода (если применимо)
3. Анализ эмоций через LLM
4. Получение контекста пользователя (цели, челленджи, история)
5. Поиск релевантной информации в RAG
6. Определение намерений пользователя
7. Построение промпта с контекстом
8. Генерация ответа через LLM
9. Извлечение рекомендованных продуктов
10. Сохранение диалога в БД
11. Генерация голосового ответа (если нужно)
12. Возврат ответа пользователю

### 2. **Проактивные уведомления**
1. Проверка триггеров (стресс, дедлайны, неактивность)
2. Генерация персонализированного сообщения через LLM
3. Отправка уведомления клиенту

### 3. **RAG поиск**
1. Векторизация запроса пользователя
2. Семантический поиск в ChromaDB
3. Получение top-3 релевантных документов
4. Форматирование контекста для LLM
