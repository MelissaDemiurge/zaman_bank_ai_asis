# 🏦 Zaman AI Assistant

AI-ассистент для Zaman Bank с эмоциональным интеллектом, геймификацией и проактивными советами по исламским финансам.

## 🎯 Что умеет

- **Эмоциональный интеллект**: Анализирует эмоции клиентов и адаптирует ответы
- **RAG-система**: Семантический поиск по базе знаний исламских финансов
- **Геймификация**: Челленджи без азарта с духовными наградами
- **Проактивность**: AI сам пишет клиентам при триггерах
- **Голосовой режим**: Текст + голос на русском и казахском языках

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
# Активация виртуального окружения
.\venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Инициализация базы знаний
```bash
python scripts/init_knowledge_base.py
```

### 3. Запуск сервера
```bash
python quick_start.py
```

### 4. Открыть интерфейс
Откройте `frontend/index.html` в браузере

## 📡 API

- **Swagger UI**: http://localhost:8000/docs
- **Health Check**: http://localhost:8000/health
- **Chat API**: POST http://localhost:8000/api/chat

## 🏗️ Архитектура

```
backend/          # FastAPI + Python
├── services/     # 7 сервисов (RAG, LLM, эмоции, геймификация)
├── routers/      # 5 роутеров (чат, цели, челленджи)
└── models/       # SQLAlchemy модели

frontend/         # Vanilla JS
├── index.html    # SPA интерфейс
└── app.js        # Логика чата

knowledge/        # База знаний для RAG
├── faq.txt       # FAQ по исламским финансам
├── products.txt  # Каталог продуктов
└── glossary.txt  # Глоссарий терминов
```

## ✅ Критерии проекта

- ✅ **Персонализированное планирование**: Диалог о целях + расчет сроков
- ✅ **Анализ расходов**: Обработка выписок + категоризация
- ✅ **Сравнительная аналитика**: Анонимное сравнение с другими клиентами
- ✅ **Финансовые цели**: CRUD + прогресс-трекинг
- ✅ **Смена привычек**: Челленджи по контролю трат
- ✅ **Визуализация**: Прогресс-бары и статистика
- ✅ **Подбор продуктов**: RAG с каталогом Zaman Bank
- ✅ **"Человечность"**: Эмоциональный интеллект + эмпатия
