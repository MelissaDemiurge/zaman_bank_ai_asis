# 🏦 Zaman AI Assistant

AI-ассистент нового поколения для Zaman Bank с эмоциональным интеллектом, геймификацией и проактивными советами по исламским финансам.

## 🎯 Основные возможности

### 1. **Эмоциональный профиль** (Emotional Financial DNA)
- Анализ эмоционального состояния клиента в real-time
- Детекция финансового стресса и склонности к импульсивным тратам
- Построение emotional DNA на основе истории взаимодействий
- Адаптивные советы в зависимости от эмоционального состояния

### 2. **RAG на исламских финансах**
- Векторизация базы знаний Zaman Bank (продукты, FAQ, глоссарий)
- Семантический поиск релевантного контекста через ChromaDB
- Строгая фокусировка: бот отказывается от нефинансовых тем
- Рекомендации только халяльных продуктов (без риба)

### 3. **Геймификация** (Исламский подход)
- Челленджи без азарта: "30 дней без импульсивных трат", "Накопить 100К"
- Духовные награды (Сабр, Баракат) вместо баллов
- Персональные поздравления через AI при выполнении

### 4. **Проактивные уведомления**
- Триггеры: стресс 2+ дня, дедлайн цели, пауза в общении
- Бот сам пишет клиенту в нужный момент
- Превентивные советы против стресс-трат

### 5. **Голосовой и текстовый режим**
- Whisper-1 для распознавания речи
- Text-to-Speech для голосовых ответов
- Seamless переключение между режимами

## 🚀 Быстрый старт

### Требования
- Python 3.10+
- PostgreSQL (или используйте SQLite для демо)
- Node.js (опционально для frontend dev server)

### 1. Установка зависимостей

```bash
# Активация виртуального окружения (уже создано)
.\venv\Scripts\activate

# Установка зависимостей (уже установлены, но на всякий случай)
pip install -r requirements.txt
```

### 2. Настройка базы данных

**Вариант A: PostgreSQL (рекомендуется)**

Установите PostgreSQL и создайте базу данных:

```sql
CREATE DATABASE zaman_db;
```

Обновите `backend/config.py`:
```python
DATABASE_URL = "postgresql://postgres:your_password@localhost:5432/zaman_db"
```

**Вариант B: SQLite (для быстрого теста)**

Обновите `backend/config.py`:
```python
DATABASE_URL = "sqlite:///./zaman.db"
```

### 3. Векторизация базы знаний

Этот шаг обязателен! Векторизация создаёт ChromaDB базу для RAG.

```bash
python scripts/init_knowledge_base.py
```

Вы увидите:
```
====================================================================
ИНИЦИАЛИЗАЦИЯ БАЗЫ ЗНАНИЙ ZAMAN BANK
====================================================================
📂 Директория базы знаний: knowledge
📄 Найдено файлов: 3
   - faq.txt
   - glossary.txt
   - products.txt
🔄 Начинается векторизация...
  Обработано 0/50
  Обработано 10/50
  ...
✓ БАЗА ЗНАНИЙ УСПЕШНО ИНИЦИАЛИЗИРОВАНА!
```

### 4. Запуск backend

```bash
cd backend
python main.py
```

Или через uvicorn:
```bash
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

Backend будет доступен на `http://localhost:8000`

### 5. Запуск frontend

Откройте `frontend/index.html` в браузере или запустите простой HTTP сервер:

```bash
cd frontend
python -m http.server 3000
```

Откройте `http://localhost:3000` в браузере.

## 🔑 Ключевые особенности

### Строгая фокусировка
Бот отказывается отвечать на темы вне банкинга/финансов. Это достигается через:
- Системный промпт с правилами
- Проверку `is_banking_related()` в RAG
- Отсутствие контекста для нерелевантных запросов

### Эмоциональная память
Каждое сообщение анализируется на эмоции → сохраняется в БД → строится профиль → влияет на будущие ответы.

### Исламская геймификация
Челленджи без баллов/рейтингов (это майсир!). Только духовные награды и персональные поздравления.

### Проактивность
Бот не ждёт, когда клиент напишет. Он сам инициирует диалог при триггерах.

## 🛠️ Технический стек

- **Backend**: FastAPI, SQLAlchemy, PostgreSQL
- **AI**: OpenAI API (gpt-4o-mini, text-embedding, whisper-1)
- **RAG**: ChromaDB
- **Frontend**: Vanilla JS, HTML5, CSS3
- **Voice**: Web Audio API, MediaRecorder
