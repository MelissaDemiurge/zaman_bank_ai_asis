# 🎯 Автоматическое управление целями

## Что реализовано

Система **автоматического определения и управления финансовыми целями** через естественный язык.

---

## ✨ Возможности

### 1. 🤖 Автоматическое определение целей

AI анализирует сообщения пользователя и **автоматически распознает** финансовые цели.

**Ключевые слова для определения:**
- "накопить"
- "цель"
- "хочу купить"
- "планирую"
- "собираю на"
- "мечтаю"
- "хочу приобрести"

**Пример диалога:**

```
👤 Пользователь: Я хочу купить квартиру за 50 миллионов тенге к 2026 году

🤖 Zaman: Отличная цель! Квартира к 2026 — это реально. Давайте подумаем, 
         как вы можете достичь этого...
         
         💡 Я заметил, что вы хотите 'Квартира за 50 миллионов'. 
         Хотите записать это в свои цели?
         
         [✅ Да, добавить в цели] [❌ Нет, спасибо]
```

---

### 2. ✅ Подтверждение создания цели

После того как AI определил цель, пользователь может:
- **Подтвердить** → цель добавляется в базу данных
- **Отклонить** → цель игнорируется

**Что AI извлекает:**
- **Название цели** (например: "Квартира")
- **Целевая сумма** (например: 50,000,000)
- **Срок** в месяцах (если указан)

---

### 3. 🗑️ Удаление целей

Пользователь может **удалить цель** через естественный язык.

**Ключевые фразы для удаления:**
- "удалить цель"
- "удали цель"
- "убрать цель"
- "убери цель"
- "отменить цель"
- "отмени цель"

**Пример диалога:**

```
👤 Пользователь: Удали цель "Квартира"

🤖 Zaman: Хорошо, удалю цель 'Квартира' из списка. Подтвердите действие.
         
         [✅ Да, удалить] [❌ Отмена]
```

## 🔧 Технические детали

### Backend API

#### **POST /api/chat**
Основной endpoint, который теперь возвращает:

```json
{
  "response": "текст ответа AI",
  "emotion": {...},
  "suggested_products": [...],
  "suggested_goal": {
    "title": "Квартира",
    "target_amount": 50000000,
    "deadline_months": 24,
    "action": "create"
  },
  "goal_action": "create"
}
```

#### **POST /api/goal/create**
Создание цели после подтверждения:

```json
{
  "user_id": "uuid",
  "title": "Квартира",
  "target_amount": 50000000,
  "deadline_months": 24
}
```

**Ответ:**
```json
{
  "success": true,
  "message": "✅ Цель 'Квартира' успешно добавлена!",
  "goal": {
    "id": "goal-uuid",
    "title": "Квартира",
    "target_amount": 50000000,
    "deadline_months": 24
  }
}
```

#### **DELETE /api/goal/delete/{user_id}/{goal_id}**
Удаление цели:

**Ответ:**
```json
{
  "success": true,
  "message": "✅ Цель 'Квартира' успешно удалена!"
}
```

## 🔍 Логика определения целей

### В `backend/routers/chat.py`:

```python
# 1. Проверка на ключевые слова
keywords = ['накопить', 'цель', 'хочу купить', ...]
if any(keyword in user_message.lower() for keyword in keywords):
    
    # 2. Извлечение цели через LLM
    goal_prompt = prompt_builder.build_goal_extraction_prompt(user_message)
    goal_response = llm_service.simple_query(goal_prompt)
    goal_data = llm_service.extract_json_from_response(goal_response)
    
    # 3. Проверка валидности
    if goal_data.get('has_goal') and goal_data.get('target_amount'):
        suggested_goal_data = {
            "title": goal_data.get('title'),
            "target_amount": float(goal_data.get('target_amount')),
            "deadline_months": goal_data.get('deadline_months'),
            "action": "create"
        }
```

### Промпт для извлечения (`prompt_builder.py`):

```python
def build_goal_extraction_prompt(self, user_message: str) -> str:
    return f"""Извлеки финансовую цель из сообщения клиента.

Верни ТОЛЬКО JSON:
{{
    "has_goal": true | false,
    "title": "название цели",
    "target_amount": числовая сумма,
    "deadline_months": количество месяцев (если указано, иначе null)
}}

Сообщение: {user_message}"""
```

## 📊 Структура данных

### Goal Model (backend/models/goal.py):

```python
class Goal(Base):
    __tablename__ = "goals"
    
    id = Column(GUID, primary_key=True, default=uuid.uuid4)
    user_id = Column(GUID, ForeignKey('users.id'))
    title = Column(String(255))
    target_amount = Column(Float, default=0)
    current_amount = Column(Float, default=0)
    deadline_months = Column(Integer, nullable=True)
    status = Column(String(50), default="active")
    progress_percentage = Column(Float, default=0)
    created_at = Column(DateTime, default=datetime.utcnow)
```
